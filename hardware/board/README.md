# 制御基板の設計データ

ユニバーサル基板に何をどう載せて、どこをはんだ付けするかの資料です。
**回路図（KiCad）と実体配線図は、同じ1つの定義から自動生成しています。**
図と回路が食い違うことが起きない仕組みになっています。

| ファイル | 中身 |
|---|---|
| **`実体配線図.pdf`** | **作業中はこれを見る。**5ページ（部品面／配線／はんだ面／チェックリスト×2） |
| `貯金箱制御基板/回路図.pdf` | 回路図。KiCad の ERC（配線ミス自動検出）を通してある |
| `貯金箱制御基板/貯金箱制御基板.kicad_pro` | KiCad で開くならこれ |

### 実体配線図の印刷

**必ず「実際のサイズ」「倍率 100%」「ページに合わせる＝オフ」で印刷してください。**
1:1 なので、印刷した紙の上に基板を載せると穴の位置がそのまま合います。

- 1ページ目 **部品面**：どの穴に何を挿すか。まずこれを見て部品を挿す
- 2ページ目 **配線（透視図）**：配線の全体像。部品面から見た向き
- 3ページ目 **はんだ面**：基板を裏返した向き。**実際にはんだ付けするときはこれ**
- 4〜5ページ目 **チェックリスト**：57本の配線を1本ずつ消し込む

穴の呼び方は「列番号 - 行記号」です。例：`13-G` は左から13列目、上からG行目。

## 作業の順番（おすすめ）

1. 部品面の図を見て、**背の低い部品から**挿してはんだ付けする
   （抵抗 → ダイオード → IC ソケット → コンデンサ → 端子台 の順）
2. 部品の足は切らずに残しておくと、次の配線でそのまま使えて楽です
3. はんだ面の図とチェックリストを見ながら、配線を1本ずつ
4. 1本つなぐごとにチェックリストの □ を塗る
5. 全部終わったらテスターの導通モードで、チェックリストの両端を当たって確認
6. **電源を入れる前に、TB1 の 1番と 2番の間が導通していないこと**を必ず確認（ショートしていたら燃えます）

配線の種類：

| 表記 | やり方 |
|---|---|
| **すずメッキ線** | 裸のスズメッキ線をまっすぐ渡す。電源のような太い流れに使う |
| **ジャンパ線** | 被覆付きの線（耐熱電子ワイヤー）を裏面で引き回す |
| **はんだブリッジ** | 隣り合う穴。はんだを盛って繋ぐ（今回は 0 箇所） |

## 回路を変えたくなったら

**`netlist.py` だけを直してください。**そこが唯一の正です。

```
cd 基板設計
python gen_all.py
```

これ1本で、

1. 繋ぎ忘れ・短絡がないか自己検査
2. 部品の配置が重なっていないか検査
3. KiCad 回路図を作り直して **ERC**（配線ミス自動検出）にかける
4. **KiCad が図から読み取ったネットと `netlist.py` を照合**（図の書き間違いを検出）
5. 配線を計算して、全ネットが本当に導通するか検証
6. PDF を作り直す

まで自動で走ります。**どこかで矛盾があればその場で止まります。**

部品の置き場所だけ変えたいときは `layout.py` を直します。

| ファイル | 役割 |

| `netlist.py` | **回路の定義（唯一の正）**。部品表とネットリスト |

## KiCad について

回路図を開いて拡大したり、自分で編集したい場合に使います。**見るだけなら PDF で足ります。**

- インストール：`winget install KiCad.KiCad`（無料。約1.5GB）
- 今回は `%LOCALAPPDATA%\Programs\KiCad\10.0\` に入っています
- `貯金箱制御基板.kicad_pro` をダブルクリック → 回路図エディタが開きます

### 知っておくとよいこと

- 回路図は**ラベル方式**で描いてあります。線を引き回す代わりに、各ピンの先に
  ネット名（`+5V`, `GND`, `LANE0_SENS` など）を書き、**同じ名前同士が繋がっている**という描き方です。
  部品数が多いときの標準的な描き方で、ERC も普通に効きます
- 見やすい「絵」としての回路図は、プロジェクト直下の `回路図.html` の方が向いています。
  こちらは全体の流れが1枚で分かるように描いたものです。**役割分担**：
  - `回路図.html` … 全体像をつかむ
  - KiCad … 正確性の担保（ERC・ネットリスト照合）
  - `実体配線図.pdf` … 実際に作る
- `PWR_FLAG` という部品が3つ入っていますが、これは**実在しない部品**です。
  ERC に「このネットは外から電源が来ている」と教えるための印です

## 注意（回路図 v2.0 からの変更点）

**アンプとの繋ぎ方を、物理的に正しい形に直しました。**

TDA2030 アンプキットは別基板で、**それ自身が入力用・出力用の端子台を持っています**。
そのため制御基板側は次のようにしています。

| 端子台 | 用途 |
|---|---|
| `TB1` | DCジャックから 12V を受ける |
| `TB2` | アンプキットへ 12V を送る |
| `TB3` | アンプキットへ 音声 を送る |
| `CN1` | センサー6本＋5V＋GND |

**スピーカーは制御基板ではなく、アンプキットの出力端子台に直接つなぎます。**
（`回路図.html` v2.0 では TB3 をスピーカー用として描いていましたが、
アンプキットの端子台と二重になるため、こちらに直しました）

端子台は 2P が **7個** 必要です（TB1・TB2・TB3 各1 ＋ CN1 に4）。カートには8個入れてあります。

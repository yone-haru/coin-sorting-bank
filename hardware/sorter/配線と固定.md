# 配線と固定（自作判別部）  2026-09-27（2026-10-06 改：中継基板を切らない ICB-86 に）

図：`配線図_中継基板.png`（電気のつなぎ方）・`ICB-86_配線図.html`（中継基板 ICB-86 のどの穴に何を付けるか。手順は `ICB-86_実装手順.md`）・`組立図_本番/06_配線.png`（線の通し方）。CAD は `判別ユニット_本番.scad`。
**`06_配線.png` と CAD の中継基板は、やめた案（32 × 28mm に切ってレールの台に留める）の位置で描いてある。**線の道筋は同じで、行き先の中継基板の位置だけが現物と違う。

## 1. 決まりごと

- **硬貨の通り道（溝の中）と、窓から落ちた硬貨の通り道（板の裏・窓の下）には線を 1 本も通さない。**
  窓から落ちた硬貨は板の裏を下流へ流れながら落ちるので、板の裏の x 60〜178 は特に何も置かない
- 線は必ず **配線の溝に押し込む** か **結束バンドで留める**。ぶら下がったままにしない（輸送の揺れで断線する）
- 基板室とは **手持ちの耐熱電子ワイヤー 7 色（AWG24）を 1 本ずつ、7 本の束** でつなぐ。LED の抵抗はレール側の中継基板（ICB-86）に置く（基板室の CN1 は今のまま）
- **買い足す物は無し**（5 章）。結束バンドの代わりに、レールの配線の溝と吊り板の印刷クリップ、熱収縮チューブの輪を使う

## 2. 電気のつなぎ方（CN1 ⇄ 線の束 ⇄ 中継基板）

手持ちの耐熱電子ワイヤー（2m × 7 色）から 40cm ずつ 7 本切って束にする。色の割り当て（手持ちの色が違えば読み替え、この表に書き込んでおく）：

| CN1 | ファームの入力 | 線の色 | つなぐ先 |
|---|---|---|---|
| 1 | GPIO4 | 青 | P3 受光（W3 の後ろ）＝500円 |
| 2 | GPIO5 | 緑 | P2 受光（W2 の後ろ） |
| 3 | GPIO3 | 黄 | P1 受光（W1 の後ろ） |
| 4 | GPIO10 | （線なし） | **予備。CN1 の 4 番と 8 番を短い線でつなぐ**（つながないと「いつも遮られている」と読まれる） |
| 5 | GPIO20 | 白 | 穴 A 受光（x=35） |
| 6 | GPIO21 | 残りの 1 色 | 穴 B 受光（x=49） |
| 7 | +5V | 赤 | 中継基板の 5V → 220Ω ×5 → 各 LED の＋（長い足） |
| 8 | GND | 黒 | 各 LED の −（×5）と各受光素子の E（×5） |

**実機の補正（2026-10-08）：** 上表は当初の施工計画。個別遮光では、物理 P1 が GPIO5（ファームの旧 P2）、物理 P2 が GPIO3（旧 P1）に届いた。どの接続点で入れ替わったかは未確認。現物をつなぎ直さず、ファームの `PIN_SS_BEAM` を P1=GPIO5、P2=GPIO3 に変更した。既存の配線図・ICB-86 図は施工計画のままなので、現物の P1/P2 の接続を調べる際はこの実測結果を優先する。

- 受光素子の C（信号）は束の信号線に直接、E は GND へ。**C と E を逆に付けると、その光はいつも「遮られている」と出る。**
  `sensortest` で遮光・通光が変わるか 1 本ずつ確かめ、おかしければ足を入れ替える
- 中継基板：**ICB-86（47 × 72mm）を切らずに使う**（2026-10-06 に決定。9/27 の「ユニバーサル基板を 32 × 28mm に切ってレールの台に M3×8 で留める」案はやめた）。
  どの穴に何を付けるかは `ICB-86_配線図.html`。220Ω ×5 は 5〜9 段に付け、基板から 3mm ほど浮かせる。
  ICB-86 は仮止めしてある（場所と留め方はこの文書にまだ書いていない）。① 判別レールの中継基板の台とそこへ留めるねじ 2 本は使わない（台は印刷済みなのでそのまま）。
  電源を入れる前に、+5V 列（I）と GND 列（J）がつながっていないこと・隣の段どうしがつながっていないことをテスターで確かめる（`ICB-86_実装手順.md`）
- 素子の足は短いので、同じ耐熱ワイヤーで継ぎ足す（LED の＋は赤・−は黒、受光の C は束と同じ色・E は黒。黒が足りなければ別の色に黒の熱収縮チューブで印）。継ぎ目は熱収縮チューブ φ1.5 で覆う

## 3. 線の通し方（`06_配線.png`）

| 線 | 通り道 | 長さの目安 |
|---|---|---|
| 通過センサーの LED 3 本（床の下） | 素子の端から **下の溝**（床の下）へ → 上流の端まで → 着地場所の前の面を上がって中継基板 | P3 30cm・P2 25cm・P1 20cm |
| 通過センサーの受光 3 本（硬貨の上） | 素子の端から **上の溝**（硬貨の上）へ → x=36 の溝の端 → 中継基板 | P3 20cm・P2 16cm・P1 12cm |
| 穴センサーの LED 2 本（橋の塔） | 塔の上から中継基板へ（近い） | 各 8cm |
| 穴センサーの受光 2 本（裏のホルダー） | ホルダーの溝から板の裏を上へ（x 28〜56 は硬貨が落ちない所）→ 板の上の辺を越えて上の溝の端へ → 中継基板 | 各 12cm |
| 線の束（7 本） | 中継基板 → 吊り板の下のクリップ 2 つ → 基板室の奥の壁の上（蓋とのすき間 8mm）から中へ → CN1 | 40cm |
| 電源ジャックの線 | 蓋の奥の電源ジャック → 吊り板の左のクリップ 2 つ → 基板室の奥の壁の上から中へ → TB1 | 35cm |
| スピーカーの線 | スピーカー → 基板室の左の壁の上から中へ → アンプ | 今のまま |

**長さの目安は、中継基板をやめた案の位置（レールの台）に置いたときの値。**ICB-86 は置き場所が違うので、線を切る前に現物の ICB-86 まで当てて長さを決める（少し長めに切る）。

**溝**：縁の上に 1mm の返しがある。線を指で押し込むと外れない。素子を差す所は縁が切れている（素子を差してから線を溝へ）。

**クリップ（吊り板の下）**：板の下にぶら下がる U 字の爪。線の束を下から押し込むと、先の 0.5mm の返しで外れない（PETG はしなるので割れない）。
7 本の束用が 2 つ（幅 4.5）、電源ジャックの 2 本用が 2 つ（幅 3.0）。板の上面は蓋にぴったり当たるので、板に穴を開けて留める方式は使えない。

**束ね方**：7 本をねじって 1 本にし、10cm おきに手持ちの熱収縮チューブ φ6 を 1cm に切って通して縮める（結束バンドの代わり）。

**素子の押さえキャップ（⑤・2026-10-07）**：素子が穴の中で動くと光の向きがずれて、`sensortest` で 0/1 がふらつく・いつも「遮られている」になる。
素子を差して足に線を継いだあと、足の側から印刷のキャップをかぶせて、素子のつばを穴の入口の面へ押し付ける（ねじなし）。
足の溝は縁まで開いているので、配線したまま横から足を溝に入れてかぶせられる。

| キャップ | 数 | 付け方 | 抜けない理由 |
|---|---|---|---|
| ⑤-1 通過 LED（床の下） | 3 | 下の溝の中で、LED のブロックに手前から押し込む | 両わきの耳が下の溝の返しに引っかかる（P3 は下流の端なので耳は上流側の 1 つだけ効く） |
| ⑤-2 通過 受光（硬貨の上） | 3 | 上の溝の中で、受光のブロックに手前から押し込む | 重さでつばの上に乗る |
| ⑤-3 穴 LED（橋の塔） | 2 | 筒は C 字（溝が下まで切れている）。はんだ付けした線を横から溝に入れ、塔の上にかぶせる | 塔にはまる（内径が塔より片側 0.1 細い。C 字なので少し開いてはまる） |
| ⑤-4 穴 受光（③ の裏） | 1 | ③ の裏全体にかぶせ、2 つの突起を ③ のねじの座ぐりに押し込む | 突起が座ぐりにはまる（ねじの頭には当たらない） |

- **10/8：試し刷り 3 回で 4 種類とも合格（ユーザー：完璧）。本番の残りは `⑤押さえキャップ_まとめ（⑤-1×2・⑤-2×2・⑤-3×1）.stl` を 1 回刷る**（`part="caps_all"`・5 個・89 × 25・押さえる面を下・サポートなし。⑤-4 と各 1 個目は試し刷りで合格した物を使う。ユーザー指示 10/8）。種類ごとの STL（⑤-1〜⑤-4）は足りない分を刷り足すとき用。試し刷りは `part="cap_test"`（4 種）・`"cap_test3"`（⑤-1〜⑤-3）・`"cap_test23"`（⑤-2・⑤-3）で出せる
- 合わないとき（`selfsort_params.scad` の「素子の押さえキャップ」の値を直して STL を出し直す）：
  ⑤-1〜⑤-3 は 10/7 の 1 回目の試し刷りで少し大きかったので、**すき間を 0 にしてデータ上でぴったりにした**（`fit_clr` 0・`cap_ear_gap` 0・つばのくぼみ `flange_d` 5.8）。2 回目で ⑤-1 はちょうど、⑤-2・⑤-3 はまだ少しゆるかったので、**⑤-2 の横の壁（`prx_clr`）と ⑤-3 の筒（`cup_clr`）を片側 -0.1（ブロック・塔より細い）にした**。まだゆるければ -0.15、きつければ -0.05。
  つばが奥まで入らない → `flange_t`（1.0。つばの厚みをノギスで測る）。
  ⑤-4 は試し刷りでよかったので `cap_clr`（0.15）・`cap_pocket_d`（6.3）のまま。突起が抜ける／入らない → `cap_peg_d`（6.8）を 7.0／6.6
- 外側は黒の油性ペンで塗る（4 章）。素子の頭を照らす光の漏れも減る
- 間に合わないときの代わり：素子の胴にマスキングテープを 1 周巻いて穴に押し込む（つばは押さえられないので、キャップより向きがずれやすい）
- 付けたら `sensortest` で 5 本とも、手でさえぎると 1・離すと 0 にはっきり変わることを確かめる

**引っ張り止め**：束は ICB-86 の空いている穴（17〜24 段。何も付けない段）2 つに余りの線を通してねじって留める（はんだ付けの所に力がかからないように）。基板室の側でも、壁の上で同じように 1 か所留める。

## 4. 印刷（PETG）

| 設定 | 値 |
|---|---|
| 材料 | **PETG**（PLA は約 60℃ で軟らかくなり、車での輸送中・直射日光で窓の寸法が狂う。PETG は約 75℃） |
| 色 | **手持ちは灰色**。灰色の PETG は赤外線を少し通すので、素子の穴の周りの壁を 1.5〜1.8mm に厚くした。さらに**印刷後、センサーのブロック（床の下の LED 3 つ・硬貨の上の受光 3 つ・橋の塔 2 つ・受光ホルダー・⑤ 押さえキャップ 9 個）の外側を黒の油性ペンで塗る**（部屋の照明や日光が壁を通って受光素子に入ると、硬貨で遮っても「明るい」と読まれる）。絞り穴（φ1.0・φ1.5）の中は塗らない |
| ノズル／ベッド | Bambu Studio の PETG の標準（240〜250℃／70℃）。テクスチャ PEI の板ならそのまま |
| 壁／インフィル | 壁 4 周・インフィル 30%・サポートなし |
| ブリッジ | 判別レールに 28〜37mm のブリッジ（着地場所・橋・関門の天井）。PETG は垂れやすいので、ブリッジの速度を遅く・ファンを強く（標準の PETG プロファイルのブリッジ設定で可）。垂れても溝の内側に 2.7mm の余裕がある |
| 置き方 | 判別レールは 179.4mm でベッド（180）いっぱい。**ブリム・スカートは切る**。真ん中に置く |
| 印刷後 | 窓の高さ（W1 21.6・W2 23.15・W3 25.1）をノギスで測る。ずれた分だけ `selfsort_params.scad` の `win_comp` を直して刷り直す。横向きの φ1.0 の絞り穴が埋まっていたら 1mm のドリルで通す |

摩擦：PETG は PLA と少し違うが、シミュレーションは摩擦 0.2〜0.5 の幅で確かめてあるので形はこのまま。

## 5. 買うもの：ねじだけ（100 均かホームセンター）

線・熱収縮チューブ・中継基板・留め具は手持ちと印刷で足りる。**ねじだけ買う**（貯金箱全体の分）。
長さを 1 種類にそろえたので、M3 は「3×8」だけでよい（中継基板の台を 2mm 高くして、3×8 の先が硬貨の溝に届かないようにした。10/06 に中継基板を ICB-86 にしたので、この台は使わない）。

| 買うもの | 本数 | 使う所 |
|---|---|---|
| なべタッピングねじ **M3×8**（木ねじ φ3×8 でも可） | **25 本**（23 本＋予備） | レールのマスト→吊り板 4／受光ホルダー 2／前板 3／中継基板 2（ICB-86 にしたので使わない。予備に回す）／基板室の制御基板 4・アンプ 4／スピーカー→蓋 4 |
| なべタッピングねじ **M4×10**（木ねじ φ4×10 でも可） | **8 本** | 吊り板→蓋のボス 4／基板室→蓋のボス 4（蓋のボスの下穴は φ3.3） |
| 平ワッシャー **M4** | **8 枚** | 上の M4 の頭の下（吊り板の座は 1.9mm と薄いので必ず） |

| 要る物 | 手持ちで使う物 |
|---|---|
| 線（束 7 本・センサーの継ぎ足し） | 耐熱電子ワイヤー 2m × 7 色（AWG24）。使うのは合計 7m ほど |
| 熱収縮チューブ | スミチューブ φ1.5・φ3・φ6（各 1m） |
| 中継基板 | ICB-86 を切らずに使う（10/06。ユニバーサル基板 B の 2 枚目は予備のまま） |
| 線の留め具 | 印刷（レールの配線の溝・吊り板のクリップ） |
| センサーの遮光 | 黒の油性ペン |

**フェルト：使わない**（床にくぼみの無い `本番STL/①判別レール.stl` を刷る）。
シミュレーションでは、普通の跳ね方ならフェルトの有無で差は無い（99.3%）。着地でよく跳ねるときだけ下がる（87.8%）。
試験で「着地した硬貨が跳ねて W1 あたりまで踊る」「1円・50円が W1 で落ちずに先へ行く」が多ければ、そのときにフェルトを考える
（くぼみ付きの予備 `①判別レール_フェルトあり（予備）.stl` も出してある）。
